## 📞 **Getting Help**

### Common Issues & Solutions

**Q: Portfolio looks broken on mobile**
A: Use local server instead of opening HTML directly

**Q: Animations not smooth**
A: Make sure you're using http://localhost, not file://

**Q: Form not working**
A: Check console (F12) for errors, or use Formspree

**Q: Colors look different**
A: Clear browser cache (Ctrl+Shift+Del)

**Q: Theme toggle not saving**
A: Check browser localStorage is enabled
